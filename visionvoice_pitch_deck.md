## 📌 Slide 2: The Problem
### Header: The Unseen Accessibility Barrier
**Subtitle**: 300M+ People Struggle with Color & Low-Contrast Digital Interfaces Daily

* **🌐 300 Million Global Population**: Color Vision Deficiency (CVD) affects 1 in 12 men and 1 in 200 women worldwide.
* **🎨 Daily Physical Barriers**: Inability to identify clothing hues, color-coded maps, charts, and subway lines.
* **💻 Digital Accessibility Failure**: Over 70% of web UIs fail basic WCAG 2.1 contrast rules, rendering text unreadable for low-vision users.

> 🎤 **Presenter Script (30s)**:  
> *"Color isn't just aesthetic—it's critical information. For 300 million people globally, distinguishing red from green or reading low-contrast text is a daily barrier that causes digital exclusion and everyday frustration."*

---

## 📌 Slide 3: The Solution
### Header: VisionVoice AI — Audio-Visual Color Perception
**Subtitle**: Converting Visual Colors into Audio Frequencies & Spoken Names

* **🔊 Audio Frequency Mapping**: Converts visual color hues into Web Audio sine-wave frequencies (`220Hz` to `820Hz`).
* **🗣️ Real-Time Color Naming**: Resolves color inputs to human-friendly color names (*Navy Blue*, *Vivid Teal*, *Gold*).
* **🧪 Dark-Mode Diagnostic Screening**: Interactive 10-plate Ishihara CVD test with instant diagnosis.
* **🖼️ Dominant Palette Extractor**: Extracts 5 accessible colors from any uploaded photo or UI mockup.

> 🎤 **Presenter Script (30s)**:  
> *"VisionVoice AI bridges light and sound. By converting visual hues into Web Audio frequencies and spoken color names, users can click any pixel or play our 8-note color piano to 'hear' exact colors."*

## 📌 Slide 4: 6-in-1 Accessibility Suite
### Header: Comprehensive Feature Engine
**Subtitle**: High-Impact Accessibility Tools in One Unified Suite

1. **🎨 Color Studio**: 3D RGB cube with click-to-sample pixel color inspection.
2. **🎹 8-Note Color Piano**: Musical soundboard keyboard (`A-K` keys) mapped from `C4` to `C5`.
3. **🧪 Ishihara Test**: Dark obsidian plate disk design for instant CVD score diagnosis.
4. **🔍 WCAG Contrast Checker**: Natural color name parser with one-click contrast fixes.
5. **📄 Document Reader & OCR**: Printed text extraction from images with Web Speech TTS.
6. **👁️ Vision Simulator Lenses**: Real-time filters for Protanopia, Deuteranopia, Tritanopia & Monochromacy.

> 🎤 **Presenter Script (30s)**:  
> *"Our platform packs six high-impact tools—from an interactive 8-note color soundboard to a WCAG contrast analyzer that understands human color names like 'Navy Blue' instead of obscure hex codes."*

## 📌 Slide 5: Production Tech Stack (8 Core Tools)
### Header: Built with 8 High-Performance Production Tools
**Subtitle**: Zero-Latency, Lightweight, 100% Client-Side Web Architecture

1. **📦 Three.js Engine**: Renders interactive 3D RGB Color Cube (WebGL 60 FPS).
2. **🔊 Web Audio API**: Real-time sine-wave frequency tone synthesizer (`220Hz`-`820Hz`).
3. **🎙️ Web SpeechSynthesis API**: Screen-reader-less voice readouts & document TTS.
4. **🎨 HTML5 Canvas 2D**: Pixel color sampling, palette extraction & Ishihara plate rendering.
5. **🔤 Space Grotesk & Obsidian Teal**: WCAG-compliant glassmorphism design system.
6. **💾 HTML5 Web Storage API**: LocalStorage preference & theme persistence.
7. **🐍 Python HTTP Micro-Server**: Fast, zero-dependency static server hosting (`server.py`).
8. **🐙 Git & GitHub Pipeline**: Version control hosted at `github.com/kunalprooo/VisionVoice-ai`.

> 🎤 **Presenter Script (30s)**:  
> *"VisionVoice AI is powered by 8 production tools and native Web APIs. By combining WebGL 3D rendering with Web Audio frequency synthesis, we achieve a 100% serverless, zero-latency accessibility suite."*
